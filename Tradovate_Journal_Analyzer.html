Profile & methodology
Personal Tradovate Performance profile. Bangkok source interpretation is based on the supplied chart/CSV cross-check, not a timezone field in the export. Explicit timestamp offsets are honored.
MNQ costs remain the TFE1 summary-supported estimate of $1.88 per matched round-trip contract. Actual full-period account reconciliation is unresolved. This is not a universal Tradeify fee schedule. Other instruments trigger gross-only statistics for the entire import.
Daily/weekday results use Bangkok exits; hour groups use Bangkok entries. Calendar dates are not journal sessions or provider trading days. All valid source records are included regardless of filename dates.
Earlier buy/sell timestamps establish entry, later establish exit. Export pnl is treated as gross per matched row without multiplying by quantity again. Rows and matched contracts do not establish execution or campaign counts.
Closed-result drawdown uses exit order, simultaneous closes batched, and initial zero. It is not intratrade equity or provider trailing drawdown. Loss streak uses exit order and original record order for ties; breakeven breaks the streak.
Duplicate candidates and invalid records block report export. One account per upload is required; account identity is not verifiable when omitted from the file. No compliance, entry quality, or breach cause is inferred.
Local-only file processing with no external fonts, libraries, analytics, or server upload. Presentation mode masks account/file identifiers only on screen; it does not anonymize original downloads.
