Data quality & calculation basis
Calendar days are not journal sessions or official provider days. This tool does not infer campaign compliance or account breach causes.


Profile & methodology
Purpose: weekly statistical reports, separate from your account journal.
Timezone: timestamps without an offset are interpreted as Asia/Bangkok, based on the supplied CSV/chart cross-check. This is a saved profile assumption, not a universal Tradovate export rule.
Costs: MNQ uses the TFE1 summary-supported $1.88 round-trip estimate per matched contract. Two daily figures and total displayed charges support this rate; full-period balance reconciliation remains unresolved. This is not a universal Tradeify rate.
Scope: this build supports the supplied Tradovate Performance schema and estimates costs for MNQ only. Other instruments receive gross-only reporting, without invented fee estimates.
Counting: rows, matched contract quantities, and campaigns are different units. Raw executions and independent campaigns are not reconstructed.
Dates: daily/weekday use Bangkok exit time; hourly uses Bangkok entry time. All valid rows in the file are included regardless of filename dates.
Drawdown: cumulative estimated net, or gross when any fee is unknown; exit order with simultaneous exits batched and initial zero. Not intratrade equity or provider drawdown.
Privacy: analysis runs inside this page. No external code, fonts, tracking, or server upload. Exported reports can contain your original filename and account ID if provided.
